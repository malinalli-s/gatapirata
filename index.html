Guía para el equipo de electrónica

Enviar de 10 a 20 mensajes por segundo, con una intensidad normalizada entre 0 y 1:

{"motion":0.65}

La ESP32 debe calcular esa intensidad a partir de aceleración sin gravedad y/o giros, con umbrales calibrados. No enviar aceleración cruda en este campo.

Desde esta página HTTPS se necesita wss:// con certificado válido o un puente seguro. Un servidor ws://192.168… puede bloquearse por contenido mixto.

Para una prueba directa en la misma Wi-Fi, sirve estos archivos por HTTP desde la ESP32 u otro servidor local y usa su dirección ws://. No desactives la seguridad del navegador.

Si no llegan datos durante 2 segundos, el audio vuelve gradualmente a 1×. La conexión real requiere firmware compatible; esta página no lo instala.
